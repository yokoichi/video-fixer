Google Pixel to mac Video Fixer

Pixel / Google フォトの VP9 mp4 を、Mac・iPhone で再生できる H.264 + AAC の mp4 に変換します。動画はブラウザ内で処理され、サーバーには送信されません。

※ 端末のメモリ制限のため、サイズの大きい動画や多数の動画を一度に処理（特に ZIP での一括ダウンロード）すると、特に iPhone では失敗することがあります。その場合は、1 本ずつ変換するか、パソコンで実行してください。

ここに動画をドラッグ＆ドロップ、またはクリックして選択
複数ファイル可

このブラウザは WebCodecs 非対応のため、互換モード（低速）で変換します。
